# iamyourphotographer website

Static GitHub Pages website for `iamyourphotographer`.

## Upload to GitHub Pages
1. Create a GitHub repository, for example `iamyourphotographer`.
2. Upload all files in this folder.
3. Go to **Settings → Pages**.
4. Source: `Deploy from a branch`; branch: `main`; folder: `/root`.
5. Add your custom domain if using `iamyourphotographer.com`.

## Cloudflare R2 image links
Replace this placeholder everywhere:

`https://YOUR-R2-PUBLIC-DOMAIN/iamyourphotographer/`

Example custom R2 domain:

`https://media.iamyourphotographer.com/iamyourphotographer/work-01.jpg`

Suggested R2 object names:
- `iamyourphotographer/cover.jpg`
- `iamyourphotographer/work-01.jpg`
- `iamyourphotographer/work-02.jpg`
- `iamyourphotographer/work-03.jpg`
- `iamyourphotographer/work-04.jpg`
